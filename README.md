# FrameOn Community Edition

This repository is a small, buildable desktop-application starter extracted from the public boundary of the FrameOn project. It includes a classic FrameOn-inspired shell, official FrameOn colors and logo, and presentation-only Audio Converter and Video Converter views. It demonstrates Avalonia UI composition, basic MVVM state, an injectable service boundary, and tests. It is intended for developers to study, rename, and extend—not as a ready-to-use media application.

The **full FrameOn app** is a separate download. Get its Windows and macOS installers from the [official FrameOn website](https://frameon.choatehome.com/#download). This repository's `main` branch contains Community Edition source; its GitHub Releases contain the official full-app installers. The automatically generated source archives attached to those releases are Community Edition source, not the full-app source.

## macOS 27 compatibility

FrameOn 1.0.4 and earlier do not launch on macOS 27. Install FrameOn 1.0.5 or later.
  
## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- A code editor or IDE that supports .NET

You do **not** need to install Avalonia separately. `dotnet restore` downloads the pinned Avalonia NuGet packages used by this project. Avalonia project templates and an Avalonia IDE extension are optional conveniences if you want XAML previews, templates, or editor tooling; they are not required to build or test this repository.

## What is included

- `FrameonVideoUtility/` — a FrameOn Community UI Starter with the main shell, local-media workspace views, reusable styling, and sample controls.
- `FrameonVideoUtility.PublicTests/` — tests for the sample catalog and view-model state.
- `FrameOn-public-source.slnx` — the solution used to restore and build both projects.

The included views retain the classic FrameOn visual language while excluding Download, Bulk Download, cookies, updates, diagnostics, telemetry, and private production workflows. Buttons, fields, selectors, and workspace navigation are presentation examples only. No file access, media engine, command construction, or network workflow is included.

The Community Edition is maintained as its own source tree. The public export copies this tree; it is not generated by stripping files from the full app.

## Build and test

From the repository root, run:

```sh
dotnet restore FrameOn-public-source.slnx
dotnet build FrameOn-public-source.slnx -c Release --no-restore
dotnet test FrameonVideoUtility.PublicTests/FrameonVideoUtility.PublicTests.csproj -c Release --no-build
```

## Build your own application

1. Rename the project, assembly, namespaces, window title, and sample text.
2. Keep, restyle, or replace the included `MainView` and shared control styles.
3. Replace `IWorkspaceCatalog` and `SampleWorkspaceCatalog` with contracts and view models for your own features.
4. Put filesystem, network, database, or platform work behind interfaces rather than directly in the UI.
5. Add tests for input validation, failures, cancellation, data preservation, and any external integration you introduce.
6. Review the licenses and security requirements of every dependency you add.

This edition is a standalone source snapshot. Do not assume it will track features, dependencies, or fixes from the full FrameOn app; maintain your own fork if you build on it.
